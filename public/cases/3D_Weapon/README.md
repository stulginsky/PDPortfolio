# Axure 3D Weapon — рабочая копия

Исходный экспорт: `E:\GitHub\Cases\3D_Weapon`. Правки выполняются только в этой копии. К витрине портфолио ресурс пока не подключён.

Локальный запуск из корня PDPortfolio: `npm run dev`, затем `http://127.0.0.1:3000/cases/3D_Weapon/home.html`.

## Загрузка и переходы

- `files/home/intro-readiness.js` сохраняет исходную заставку и задерживает только её финальный переход до события Sketchfab `viewerready`. Iframe находится в стабильном слое: анимации Axure не должны перемещать его после запуска.
- `resources/model-navigation.js` подключён ко всем пяти HTML-страницам. Он перехватывает штатные локальные переходы Axure, предзагружает целевую страницу при наведении/фокусе и сохраняет уже готовые страницы в прикреплённых iframe. Изображения, стили и действия исходного экспорта остаются в своих страницах.
- Незагруженная цель не заменяет текущий экран: переключение выполняется после `viewerready`. Последний выбор имеет приоритет. При ошибке/тайм-ауте доступна повторная загрузка.
- Загрузка остальных моделей не запускается автоматически. Посещённые страницы сохраняются до закрытия/обновления вкладки; неактивные Sketchfab-viewer останавливаются через API, при возврате запускаются снова. Одновременно кэшируются не более пяти исходных страниц (Home и AK используют одну модель, но остаются разными страницами экспорта).
- Адресная строка и история обновляются через History API. Прямое открытие и обновление каждого из пяти исходных адресов поддерживаются. Новая вкладка создаёт собственный кэш.
- Таймер исходной страницы остаётся единственным владельцем отсчёта. Скрытые страницы не запускают свои циклы и не сбрасывают переменные; активная страница получает текущие показания владельца.
- Sketchfab SDK `1.12.1`, модели и текстуры загружаются с серверов Sketchfab; доступ к сети нужен для первого открытия модели.

Мобильная адаптация ещё не выполнена. Изменения ограничены рабочим ресурсом, компоненты портфолио не изменены.
