# Review & Plan

## Краткий вывод

Проект можно продолжать. Техническая база рабочая: Nuxt/Vue, компонентная структура, контент в `content`, ассеты в `public`, дизайн-токены в CSS, отдельный typograf-пайплайн перед сборкой.

Сейчас проект выглядит как рабочий прототип после активной сборки. Главная задача перед дальнейшей разработкой - стабилизировать базу: git, статическая генерация, контент-пайплайн и минимальные проверки.

## Что уже хорошо

- Стек подходит для портфолио: Nuxt + Vue, возможна статическая генерация.
- `npm run build` проходит успешно.
- Структура проекта читаемая: `app/pages`, `app/components`, `app/types`, `app/utils`, `content`, `public`, `scripts`.
- Карточки главной вынесены в JSON и типизированы.
- Есть дизайн-токены в `app/assets/css/tokens.css`.
- Есть typograf-пайплайн: `typograf:apply`, `typograf:preview`.
- Контент из Notion уже частично присутствует в `content/notion/cases`.

## Главные проблемы

### 1. `npm run generate` падает

Статическая генерация сейчас завершается ошибкой из-за двух ссылок из кейса Chirp:

- `/cases/nested-chirp-ai-check`
- `/cases/nested-chirp-brand`

Ссылки есть в `app/pages/cases/chirp-ai-health-assistant.vue`, но соответствующих Vue-страниц в `app/pages/cases` нет.

При этом markdown-источники для этих страниц уже есть:

- `content/notion/cases/nested-chirp-ai-check.md`
- `content/notion/cases/nested-chirp-brand.md`

Это блокер для деплоя на GitHub Pages/SSG.

### 2. Git-состояние не стабилизировано

`git status --short` показывает весь проект как `untracked`. Значит сейчас нет нормальной зафиксированной базы, от которой можно безопасно продолжать.

Перед активной разработкой нужно:

- проверить `.gitignore`;
- исключить служебные директории и build-артефакты;
- сделать первый осознанный commit.

### 3. Архитектура описывает больше, чем реализовано

В `architecture.md` заложены:

- light/dark theme;
- i18n `ru/en`;
- GitHub Pages `baseURL`;
- полный prerender маршрутов;
- Notion как CMS.

В коде это пока реализовано частично. Это нормально для прототипа, но важно не считать эти пункты готовыми.

### 4. Контент-подход пока смешанный

Сейчас есть ручные Vue-страницы кейсов и одновременно markdown-контент из Notion. Нужно выбрать основной путь:

- либо кейсы остаются ручными Vue-страницами;
- либо страницы генерируются/собираются из `content/notion/cases`.

Для масштабирования лучше второй путь, но он требует аккуратного маппинга markdown/Notion в компоненты.

### 5. SEO пока минимальный

`useSiteHead` сейчас задает в основном `title`. Нужно добавить:

- `description`;
- Open Graph;
- canonical URL;
- `lang`;
- при i18n - `hreflang`.

### 6. Нет базовых quality gates

В `package.json` нет отдельных скриптов:

- `typecheck`;
- `lint`;
- тесты;
- CI-проверка `generate`.

Минимально стоит добавить typecheck и проверку генерации перед деплоем.

## Приоритет на следующий рабочий заход

1. Привести git в порядок.
2. Починить `npm run generate`.
3. Выбрать стратегию для кейсов: ручные страницы или генерация из markdown.

После этих трех пунктов проект станет гораздо спокойнее развивать.
