# Axure 3D Weapon — рабочая копия

Исходный экспорт: `E:\GitHub\Cases\3D_Weapon`. Правки выполняются только в этой копии. К витрине портфолио ресурс пока не подключён.

Локальный запуск из корня PDPortfolio: `npm run dev`, затем `http://127.0.0.1:3000/cases/3D_Weapon/home.html`.

## Загрузка и переходы

- `files/home/intro-readiness.js` сохраняет исходную заставку и задерживает только её финальный переход до события Sketchfab `viewerready`. Iframe находится в стабильном слое: анимации Axure не должны перемещать его после запуска.
- `resources/model-navigation.js` подключён ко всем пяти HTML-страницам. Он перехватывает штатные локальные переходы Axure, предзагружает целевую страницу при наведении/фокусе и сохраняет уже готовые страницы в прикреплённых iframe. Изображения, стили и действия исходного экспорта остаются в своих страницах.
- Незагруженная цель не заменяет текущий экран: переключение выполняется после `viewerready`. Последний выбор имеет приоритет. При ошибке/тайм-ауте доступна повторная загрузка.
- Загрузка остальных моделей не запускается автоматически. Посещённые страницы сохраняются до закрытия/обновления вкладки; неактивные Sketchfab-viewer останавливаются через API, при возврате запускаются снова. Одновременно кэшируются не более пяти исходных страниц (Home и AK используют одну модель, но остаются разными страницами экспорта).
- Адресная строка и история обновляются через History API. Прямое открытие и обновление каждого из пяти исходных адресов поддерживаются. Новая вкладка создаёт собственный кэш.
- Таймер управляется общим контроллером: одна конечная отметка времени, исходная длительность 16:12:00, формат HH:MM:SS. Остаток рассчитывается по фактически прошедшему времени, отрицательные значения исключены; на 00:00:00 отсчёт останавливается. Старые рекурсивные циклы Axure отключены на всех страницах и в обоих состояниях таймера. Предзагрузка и переходы не сбрасывают отсчёт.
- Sketchfab SDK `1.12.1`, модели и текстуры загружаются с серверов Sketchfab; доступ к сети нужен для первого открытия модели.

## Адаптивная композиция

Согласованные визуальные источники: 3D-weapon-min-1280.png и 3D-weapon-min-760.png. В диапазоне 1280–1920 макет имеет фиксированную ширину1280px и центрируется без растяжения; нижний профиль соответствует мобильному референсу 768×1200 и уменьшается для более узких экранов. Технические профили: base (<760), min-760 (760–1279), min-1280 (от1280).

- resources/model-layout.js / .css собирают композицию из исходной графики и назначают начальное кадрирование камеры. Все четыре страницы имеют горизонтальное меню AK-47 → M4A1 → AWP → нож. Активный пункт использует существующий увеличенный растр и чёрный Т-указатель.
- Оригинальные HTML-слои остаются в документе как исполнитель действий Axure и владелец данных таймера; они исключены из пользовательского фокуса. Сценарий кейса заканчивается кликом по «Получить»: у кнопки сохранены hover и pressed, переключение на Steam и внешние переходы отключены. Новое меню использует прежний контроллер кэша и истории. Sketchfab iframe перемещается в стабильный слой до запускаSDK и больше не пересоздаётся при переключении.
- Название и «Прямо с завода» отображаются отдельными окнами исходного PNG. Порядок блоков, ширина кнопки и положение предложения/таймера соответствуют утверждённым референсам. Самостоятельный Axure-ресурс сохраняет собственную графику и не меняет компоненты DS портфолио.
- Растровые части кнопок взяты из Figma 4Real3Dweapon-case, узел7:86. В реестре сохранены Default/ActivePressed, Hover и два исходных Steam-состояния; в интерфейсе используются только первые два. Ассеты включают левые/правые края42×128, заполнитель1×128 и надпись211×128 либо268×128. Растягивается только середина; надпись, углы и тени сохраняют естественные размеры. Полный реестр с именами Figma, node ID, размерами и SHA256: images/buttons/manifest.json. В runtime нет временных Figma URL.
- Тело кнопки:325px на desktop и435px в мобильном референсе; на узком экране ограничено доступной шириной. Согласованные анимации заставки, ожидание viewerready, предзагрузка, история, неинтерактивный значок3D и корректный HH:MM:SS сохранены. Начальный ракурс3D остаётся интерактивным, исходное автовращение сохранено.

Ресурс подключён к странице `/cases/4real-3dweapon`: карточка Creative на витрине открывает кейс, а живой лендинг в нём закрывает описание при прокрутке. В этом встраивании колесо мыши прокручивает внешнюю страницу, не масштабируя камеру; в самостоятельном лендинге прежнее управление сохранено. Высота iframe следует за адаптивным содержимым, футер не дублируется. Публикация не выполнялась.

## Контрактный Footer

Футер генерируется из production `app/components/DsFooter.vue`, его scoped CSS, канонических токенов, Favicon и Roboto Flex. Отдельной ручной копии компонента нет; в браузере лендинга Vue не загружается. Обновление: `npm run generate:weapon-footer`; команда также запускается перед `dev`, `build` и `generate`.

HTML в пяти страницах и файлы `resources/portfolio-footer/` являются результатом генерации. Источники и их SHA256 перечислены в `resources/portfolio-footer/manifest.json`. Редактировать нужно production-компонент и его источники, затем повторно запускать генератор.

До410px используется вертикальная компоновка, с410px — горизонтальная. Отступы16px снаружи,64px внутри по вертикали и gap16px, иконка24px, текст16px/600/150% сохранены из компонента. Footer следует за основным содержимым; на больших экранах основная сцена учитывает высоту футера. При переходах используется один Footer хоста, экземпляры внутри кэшированных страниц скрыты. На первом экране Home футер появляется после завершения заставки.
