**Нажатие и выбранное состояние различаются.** Обычный клик не делает кнопку выбранной. Если она управляет меню, приложение хранит состояние открытия и передаёт его в `toggled`.

## Использование

### Действие

В Vue импортируйте компонент из `app/components/DsButton.vue`. Внутри приложения Nuxt компонент доступен через auto-import.

```vue
<DsButton text="Сохранить" @click="save" />
```

### Переход по ссылке

```vue
<DsButton text="Открыть проекты" tag="a" href="/" />
```

### Раскрытие панели

Состояние хранится у родителя. Одна переменная управляет оформлением кнопки, доступным состоянием и видимостью панели.

```vue
<script setup>
import { ref } from 'vue'
import DsButton from '~/components/DsButton.vue'

const open = ref(false)
</script>

<template>
  <DsButton
    text="Подробности"
    icon-right
    :icon="open ? 'ChevronUp' : 'ChevronDown'"
    :toggled="open"
    aria-controls="button-example-details"
    :aria-expanded="open"
    @click="open = !open"
  />
  <div v-show="open" id="button-example-details">Содержимое панели</div>
</template>
```



## Доступность

- Подпись должна объяснять действие: «Сохранить», «Открыть проекты», «Показать подробности».
- `Tab` переводит фокус на кнопку; `Enter` и `Space` активируют кнопку действия. Ссылка активируется клавишей `Enter`.
- `ariaLabel` задавайте, когда видимой подписи недостаточно; доступное название должно сохранять её смысл.
- Для раскрываемой панели передавайте `ariaControls` и `ariaExpanded`. Эти свойства описывают связь и состояние, а видимостью управляет приложение.
- Для переключателя режима используйте `toggled` вместе с `aria-pressed`. Для раскрытия панели используйте `aria-expanded`.
- У ссылки с `disabled` блокируется переход, но она остаётся в порядке фокуса. Если действие недоступно, объясните причину рядом с элементом.
