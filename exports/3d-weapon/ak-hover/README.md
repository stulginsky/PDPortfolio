# AK-47 — hover-последовательность

10 PNG-кадров: `frame-01.png` → `frame-10.png`.

- Каждый кадр: 945 × 564 px, белый непрозрачный фон.
- Движение: поворот от ракурса вдоль ствола к раскрытому боковому виду с постепенным приближением.
- Полная длительность перехода: 300 мс. Положения кадров и временные отметки находятся в `sequence.json`.
- Замедление `easeOutCubic` уже учтено в положениях камеры. При воспроизведении распределять кадры по времени равномерно, без повторного применения easing.
- При уходе мыши можно воспроизводить последовательность в обратном порядке, начиная с текущего кадра.
- Кадры сняты непосредственно из 3D-сцены через Sketchfab Viewer API. Автовращение, интерфейс и размытие глубины резкости при съёмке отключены.
- Источник: https://sketchfab.com/models/5d103e427b1c4d9db2676bdf50b0d12a

В работающий сайт последовательность пока не подключена.
