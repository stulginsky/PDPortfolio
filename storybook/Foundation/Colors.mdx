# Colors

Цвета PDPortfolio DS. Источник правды — [Figma PDPortfolio-Prod](https://www.figma.com/design/V28Wl8M0ipiH4neDPjxKys/PDPortfolio-Prod?node-id=0-1).
Все значения читаются из `tokens.css` — CSS custom properties, отображённые из Figma Variables.

## Decorative — декоративные фоны

Отдельная группа внутри Primitive и Semantic, не новая коллекция. Только оформление витрины: не текст, управляющие элементы или продуктовые статусы.
