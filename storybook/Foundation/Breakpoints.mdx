# Responsive Breakpoints

Layout guide styles описаны отдельно в Foundation/Layout guide styles.1920 - 2cols — стандартный DS-layout;1920/720 в именах направляющих сами по себе не вводят CSS-breakpoint.

DS использует `min-width` breakpoints. Свойство `Breakpoint` в Component Sets: `base` — ниже первого порога, `min-N` — начиная с N px.
