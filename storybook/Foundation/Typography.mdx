# Typography

21 текстовый стиль Roboto Flex. Источник: `ds/foundation.md`.
Общие оси вариативного шрифта: `GRAD=0, XOPQ=96, XTRA=468, YTAS=750, YTDE=-203, YTFI=738, YTLC=514, YTUC=712, slnt=0, wdth=100`.

> **Важно:** Имена стилей не совпадают с именами шкалы размеров. Например, `DS/Heading/3xl` привязан к `text/size-4xl` (72px). Нельзя переносить значения по совпадению суффиксов.
