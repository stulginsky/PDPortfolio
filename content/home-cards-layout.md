# Раскладка карточек на главной (`index`)

Справочник по полю `index` в `content/home-cards.json`.  
Вёрстка: **три колонки**, плитки стопкой (masonry без вертикальных дыр). Позицию задаёт только `index`, не порядок объектов в JSON.

Источник макета: [Figma — Main `46:489`](https://www.figma.com/design/V28Wl8M0ipiH4neDPjxKys/Site-Portfolio-Bazarov?node-id=46-489).

## Сетка на десктопе (ширина > 1100px, 3 колонки)

```
        Колонка 1      Колонка 2           Колонка 3
        ─────────      ─────────           ─────────
Ряд 1   [ index 1 ]    [ index 2 ]         [ index 3 ]
Ряд 2   [ index 4 ]    [ index 5 ]         [ index 6 ]
```

## Формулы

Из `index` (при `columnCount = 3`):

- **Колонка:** `(index − 1) % 3 + 1`
- **Ряд:** `floor((index − 1) / 3) + 1`

Из координат (если удобнее думать «колонка + ряд»):

- **index** = `(ряд − 1) × 3 + колонка`

Примеры: колонка 2, ряд 1 → `index = 2`; колонка 1, ряд 2 → `index = 4`.

В коде: `app/utils/home-cards.ts` — `getCardColumn`, `getCardRow`, `indexFromPlacement`, `getCardsInColumn`.

## Как переставить плитку

1. Открыть `content/home-cards.json`.
2. Найти карточку по `title`.
3. Поставить нужный `index` (1…6), **без дублей** у видимых карточек (`show: true`).
4. Сохранить и обновить страницу.

Порядок объектов в массиве JSON **не влияет** на экран — сортировка по `index`.

### Примеры

| Задача | Что сделать |
|--------|-------------|
| Chirp **слева** от Vendor (верхний ряд) | Chirp → `1`, Vendor → `2` |
| Поменять местами LeCar и Cash Desk (правая колонка) | LeCar → `6`, Cash Desk → `3` |
| Скрыть карточку | `"show": false` — `index` можно оставить |

После смены индексов остальные карточки при необходимости перенумеруйте, чтобы не было двух одинаковых `index`.

## Планшет и мобилка

| Ширина | Колонок | Как читается `index` |
|--------|---------|----------------------|
| > 1100px | 3 | сетка 3×2, как выше |
| 721–1100px | 2 | `(index − 1) % 2 + 1` — две колонки |
| ≤ 720px | 1 | все карточки сверху вниз по возрастанию `index` |

На узких экранах та же нумерация, меняется только число колонок.

---

## Что не путать

| Поле | За что отвечает |
|------|-----------------|
| `index` | **Место** на сетке (колонка и ряд) |
| `height` | **Высота** карточки в пикселях (вид из Figma) |
| `show` | Показывать на главной или нет |

---

## Почему не `column-count` в CSS

При `column-count: 3` браузер **балансирует высоту** колонок и может поставить высокую карточку (например Chirp) под низкую (Vendor), даже при правильном `index` в данных.

В проекте три **flex-колонки** в `app/pages/index.vue`: каждый `index` попадает в свою колонку предсказуемо.
