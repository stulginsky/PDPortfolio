# Дизайн-система портфолио

Здесь собраны основы оформления, компоненты и композиции. Интерактивные примеры помогают изучить их внешний вид, состояния и поведение.

## С чего начать

- <a href="./?path=/docs/foundation-colors--docs" target="_top">Foundation — основы оформления</a>: цвета, типографика, отступы и адаптивные сетки.
- <a href="./?path=/docs/components-button--docs" target="_top">Components — компоненты</a>: отдельные элементы интерфейса, их свойства и состояния. Начните с Button.
- <a href="./?path=/docs/compositions-case-heroes-chirp-ux-hero--docs" target="_top">Compositions — композиции</a>: сочетания компонентов и графики для конкретных задач. Начните с hero кейса Chirp UX.

## Как смотреть примеры

Откройте Docs нужного элемента в боковом меню. В интерактивных примерах можно менять доступные свойства через Controls. Варианты и отдельные сценарии расположены под названием элемента.

Некоторые примеры содержат Sandbox — рабочие настройки демонстрации. Они помогают исследовать поведение, но не являются частью интерфейса портфолио.
