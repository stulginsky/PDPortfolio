# Реестр оптимизированных PNG

`content/assets/optimized-png.json` хранит 116 PNG, полученных после ручной оптимизации 30 октября 2026 года: путь, исходный и итоговый SHA256, объём, размеры и ссылки на использующие файлы из исходного манифеста.

Файл считается прошедшим оптимизацию только при совпадении пути и текущего SHA256 с итоговым SHA256 в реестре. Изменённое содержимое требует повторной оптимизации. Не удаляйте старые записи при добавлении следующей партии; обновляйте записи соответствующих путей после проверки возвращённых файлов.

Проверка новых и изменённых PNG:

```powershell
node scripts/export-png-for-optimization.mjs
```

Выдача файлов с сохранением иерархии в новую папку внутри tmp:

```powershell
node scripts/export-png-for-optimization.mjs --export tmp/png-for-optimization
```

Скрипт сканирует все отдельные PNG в public, включая пока неиспользуемые. Если нужна выдача только используемых изображений, дополнительно проверьте их использование. Встроенные в SVG изображения не сканируются. Команда не изменяет реестр и исходники и не перезаписывает существующую папку выдачи.
